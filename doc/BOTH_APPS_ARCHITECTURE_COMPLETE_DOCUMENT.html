4) Configuration Architecture

Android

  • build.gradle.kts (root): shared build setup
  • settings.gradle.kts: module + repository resolution
  • gradle.properties: gradle flags/properties
  • app/build.gradle.kts: app SDK/deps/signing/proguard
  • version.properties: VERSION_CODE=6, VERSION_NAME=1.0.5
  • app/src/main/AndroidManifest.xml: permissions, app entry, provider

Web + AWS

  • package.json: scripts/deps/version 1.0.2
  • tsconfig.json: TS build strict settings
  • aws/template.yaml: infra resources and API routes
  • aws/samconfig.toml + samconfig.toml: deployment defaults
  • public/sw.js: release cache namespace

7) Security, Persistence, and Operations

  • JWT-based auth for registered users; guest mode remains local-first.
  • Spectator access uses scoped token in URL query parameter and version checks.
  • Ownership checks in Lambda protect cross-user updates.
  • Android uses Room; Web uses LocalStorage + cloud merge/sync queue logic.
  • AWS stack: API Gateway, Lambda, DynamoDB, Secrets Manager, S3, CloudFront.
  • Release best practice: bump service worker cache key and invalidate CloudFront.
